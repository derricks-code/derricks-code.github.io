# Derrick Njoroge Portfolio

Static portfolio for GitHub Pages.

## Deploy
1. On GitHub, create a public repository named exactly derricks-code.github.io
2. Upload index.html, .nojekyll and README.md to the main branch
3. Open Settings, Pages, and set Source to "Deploy from a branch", branch main, folder root
4. Your site goes live at https://derricks-code.github.io within a few minutes
